# 自动分拣：编码器速度闭环接入

本入口继承 `tmp/autosort-boot-20261103` 的当前物料分类修复版本。
送料、识别、到位、分类、抓取和返回流程沿用现有 `main.cpp`；视觉区域及动作协议不变。

`traverse/drive.cpp` 在带编码器的 Features=30 固件上使用前馈加 PI 调节 PWM。
Features=14 仍使用原有固定占空比，因此软件可与旧固件配合，回退时不改变分拣流程。
新固件合并外部 A/B 输入与原 8 秒送料协议，保持 `RunLimitMs=8000`。

原有位置调度仍在 X=1100 从 75 档切换到 50 档，X=1213 触发停车。
编码器模式下，两档分别对应理论全速的 75% 和 50%，约 3.04、2.03 cm/s。
带面速度用四倍频计数差计算；当前仅正向送料，使用计数差的绝对值，因此 A/B 极性不改变目标速度。
实际 PWM 随负载调整，输出范围为 0..100%。

板端参数文件 `/opt/autosort/encoder.ini`，默认值见同名文件。比例来自
11 PPR、四倍频、169:1 减速、20/31 同步轮、约 2 cm 滚筒；属于理论值，未实测标定。
后续可直接调整比例、全速、PI 增益和速度滤波时间，无需改分拣状态机。
