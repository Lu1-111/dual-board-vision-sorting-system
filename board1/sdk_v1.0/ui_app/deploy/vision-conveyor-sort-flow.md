# 视觉定位、停带与机械臂分拣

用户确认的目标流程是：视觉提供物块位置与类别，传送带沿 X 输送到机械臂前方的抓取线；确认停稳后，机械臂使用实际 X/Y、预设 Z 抓取，并按类别放置；机械臂避让且相机回到标定姿态后，放行继续输送。

用户已选择每个识别类别对应一个放置区。当前工程的五类模型配置为 red、yellow、blue、green_good、green_defect，分别预留 A–E 五个区。应按 NPU JSON 的 class_name 分流，不能使用 color 字段合并绿色合格与绿色缺陷。`sort-zones.template.json` 记录待标定的放置坐标和抓放参数；null/confirmed=false 不可作为运动参数。该模板可通过 UI“分类放置区”载入、填写并保存；未确认的实测参数不会启动自动分拣。

## 职责

视觉提供稳定 object_id、帧序号、采集时间、位置、类别与置信度。像素坐标先经固定平面的标定转换为同一机械臂坐标系的厘米坐标。分类结果必须与该目标绑定，不能在抓取中被新一帧的另一个物体替换。

PS 执行目标管理、位置外环和分拣协调；PL 执行 PWM、编码器 AB 四倍频计数、寄存器接口和看门狗。坐标不直接作为电机电信号。

传送带只调节 X，Y 的横向偏差交给机械臂。抓取线必须处于机械臂在整个允许 Y 范围内可达的位置。UI 中 20 cm 是模拟默认值，不能直接作为现场抓取线。

## 顺序与互锁

1. 机械臂在拍摄/避让姿态，传送带进料；检测并锁定一个目标。
2. 目标接近抓取线，传送带减速；结合视觉位置和编码器速度确认停稳。
3. 固定该目标的实际 X/Y 和类别，停止带面输出；此时不再用移动相机的新坐标更新被抓目标。
4. 按固定抓取高度 Z 和安全接近/抬升高度规划抓取。夹爪开合、腕旋和避障路径需要现场配置。
5. 根据目标类别选择放置位置，执行抬升、转移、放下和松夹爪。
6. 机械臂返回拍摄/避让姿态；允许下一目标进入，传送带恢复进料。

放行不应重读同一个旧文件并把刚处理的物块编号为新目标。已有 UI 保留全局帧游标；像素模式在放行后要求新目标首先出现在减速区上游。该限制要求足够物料间距，尚不支持多个相近目标或遮挡后的身份恢复。

失去视觉、越界、编码器异常或动作失败时停止联动。无有效类别/放置位置时保持等待，不能任意选择分拣区。正常停带为禁能滑行，软件的 holding 不是主动制动或机械锁止。

## 当前实现边界

已实现传送带控制器、PL 核心/GP0 接线、UI、模拟流程、单候选视觉读取和动作组互锁。真实电机引脚尚未接入，板上 UI 的模拟演示不移动物理传送带或机械臂。

当前“执行已载入抓放动作组”是显式操作的联调入口。现另有“开始视觉自动分拣”：停稳后锁定实际 X/Y 与 class_name，预检整条九帧抓放/返回序列的逆解和关节范围，再执行。未知类别、参数缺失、姿态不一致、被手动打断或返程失败都会停止联动。硬件自动分拣须确认关节和几何标定，且不允许模拟传送带配真实机械臂自动抓取。模拟测试不代表已验证无碰撞、夹住物体或真实到位。

现场还需提供/确认：像素平面标定、抓取线与 Y 走廊、抓取 Z/抬升高度、夹爪参数、各类别放置坐标和返回拍摄姿态。舵机目前没有关节位置反馈，动作结束和拍摄姿态检查依据最后发送的命令，不等于已测得真实到位或抓取成功。

自动程序每轮按：接近→下降→闭爪→抬升→转移→下降→开爪→抬离→返回记录的观察脉宽。逆解沿用上一帧关节作为种子，俯仰固定；所有目标先换算检查脉宽，再开始运动。该程序采用关节插值，所填抬升高度不保证整段插值路径恒高，必须现场验证障碍物间隙。

分拣完成依赖独立任务编号及 completed 状态，停止/切页/手动动作会变成 interrupted，不当作完成；返程比较观察脉宽允许 1e-6 μs 的数值舍入差，同时要求坐标原点、关节映射、几何等模型完全一致。每次参数编辑停止流程并撤销参数确认；配置不会自动使能机械臂。
