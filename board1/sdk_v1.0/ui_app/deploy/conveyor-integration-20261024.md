# 传送带与机械臂集成记录

目标：在实物传送带尚未连接时，完成控制器、主 PL 总线和 HDMI Qt 页面的集成，验证模拟到位、抓取互锁与放行流程。实物带速、编码器、抓取路径和定位精度留待机构就绪后验证。

## 已实现

- Qt 左侧新增“传送带联动”，与机械臂共用同一个 ArmPage 会话；包含带面示意图、状态、厘米坐标、速度/PWM、模拟演示、停止、复位、放行、参数与视觉配置。
- 默认模拟传送带、机械臂未启用。模拟演示为到位→虚拟抓取→放行→停止，不使真实机械臂运动。切离页面或切换模式停止传送带；切换模式同时释放后端，必须重新连接。
- 到位后提供机械臂逆解预览。手动执行已载入动作组时先检查机械臂状态，在抓取期间持续禁止带面使能。动作组必须包含抓、放、避让和返回拍摄姿态；另新增自动分拣模式，按停稳 XY 和类别生成完整抓、放、返回观察姿态序列；现场参数仍须填写确认。
- 可持续读取 NPU JSON：camera_pixel 使用同一平面标定转换厘米，并检查图像尺寸、拍摄姿态、帧新鲜度、候选数量和相邻位置；belt_cm 可接上游已标定 X/Y 与稳定 object_id。Y 用于工作走廊检查，不能靠输送带修正。
- 20 ms 控制心跳、视觉超时、最大周期、速度/方向/计数异常和 PL 看门狗。picking 状态暂停移动相机的视觉超时，仍检查带面位移与周期上限。
- PL 在原 GP0 AXI4→AXI-Lite 转换器后分流 0x80060000/4 KiB，实际时钟 75 MHz。当前 BENCH_ONLY=1，电机输出硬锁低且未引出，内部 AB 注入可供板上自检。

新 BOOT/设备树尚未写入启动卡，板上 PL 仍为原版本；不能访问新寄存器地址。UI 和 CLI 的板上模拟通过，不等于新增 PL 已通过板上自检。未确认的原始候选位流留在 `soc_prj_Runs/phy_conveyor_20261024`，不能直接视作可发布镜像。

## 视觉输入

NPU timestamp_ms 保留为结果时间。新增 capture_timestamp_ms 在 DMA 启动前记录，通过异步队列随同一张输入传到推理结果，source=dma_submit_lower_bound；它不是传感器曝光硬件时间。可用 --capture-age-guard-ms 明确给出实测曝光/读出额外年龄上界。硬件 UI 要求该软件采集源必须提供 capture_age_guard_ms，缺失即停止，并把它计入图像年龄；默认不猜数值。图片文件模式不标记成实时采集帧。模拟旧结果时间仍加 120 ms，仅用于接口联调。还需实测端到端延迟并调整带速和停止提前量。坐标输入须与机械臂当前厘米坐标系和固定 Z 平面一致。

像素候选关联只适用于区域内唯一目标；多个候选、跳变、标定区外及旧数据会拒绝或停止。复杂遮挡、多物体身份跟踪尚未实现。相机随机械臂移动后，放行前须回到标定拍摄姿态。
