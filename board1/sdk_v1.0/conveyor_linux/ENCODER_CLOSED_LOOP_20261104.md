# 传送带单轴闭环接入

2026-11-04：本次是编码器接入与单轴速度控制候选版本。未写板、未发送电机或机械臂运动命令。实际闭环效果须在新位流验证和标定后测量。

## 接线与固件

用户确认 A=Y6（CEP18）、B=V10（CEP16），电平转换已处理。端口经过 system_top → design_0 → conveyor_gp0 → conveyor_axi 接入既有两级同步和 AB 四倍频计数器。Y6/V10 使用 LVCMOS33 输入；生成脚本检查引脚占用，重新运行时保留选择的运动模式。

Features 寄存器 0x2C 新增 bit4（0x10）：外部编码器已在工程接线。它不是编码器健康、比例标定或实机验收标志。

- 闭环候选：Features=16，BENCH_ONLY=0、JOG_ONLY=0，保留 250 ms 心跳看门狗。
- 受限点动候选：Features=22，保留 1 秒硬件点动截止，闭环控制器拒绝此模式。
- 旧镜像 0/6/14，以及内部 AB 注入 bench 镜像，都不能用于新增闭环控制器。

`src/conveyor/integrate_conveyor_motor.py --closed-loop` 选择闭环源码配置；`--jog-only` 选择点动配置。无参数时保留已有配置。改变配置必须重新实现 FPGA，不能通过 Linux 写寄存器切换。闭环配置没有点动模式的 1 秒硬截止，不应与旧点动程序混用。急停/驱动器故障外部输入仍未接入；编码器卡滞检测不是电流过载保护。

新加入的异步输入仅对 pin→第一级同步寄存器设例外；两个同步级之间保留时序检查并施加 1 ns 延时预算。完整实现需要检查这四个同步寄存器及整板时序，不能以 RTL 仿真代替布局布线。

## 编码器比例

用户图片给出 AB 双相霍尔、11 PPR 基础脉冲，另一表格给出 22 CPR，计数口径须实测核对。按每通道 11 周期和 PL 四倍频计算，电机轴每转 44 count。

项目已记录 169:1 减速比、电机同步轮 20 齿、滚筒同步轮 31 齿、滚筒直径约 2 cm。以上条件成立时：

`cm_per_count = π × 2 × (20/31) / (11 × 4 × 169) ≈ 0.000545140928`

即约 1834.388 count/cm。这只是理论参考，滚筒有效直径、减速比及脉冲定义仍需核对。不要把此值自动写成实测配置。`encoder_sign` 也必须根据实际前进方向确定。

## 调试顺序

1. 新位流完成时序和管脚核查后部署，确认 UIO name=conveyor、地址 0x80060000；读取 Features，核对构建身份。
2. 用编码器监视模式读计数、累计变化和错误数。该模式持续写禁能，不能与另一个点动进程同时使用。不要强行反拖不能反拖的减速机构。
3. 用独占控制的受限点动或合适的外部测量方式记录一段实际带面位移、起止原始计数和方向。点动后确认输出禁能；固定一个模式和操作者，避免两个程序争用 UIO。
4. 用已有 `tools/belt_calibration.py encoder-scale --travel-cm <实测厘米> --before <起始计数> --after <结束计数>` 换算比例。该工具处理 32 位计数回绕。重复不同长度验证比例与方向。
5. 复制 `conveyor.hardware.template.ini` 为实测配置，填入 cm_per_count 和 encoder_sign。模板 cm_per_count=0 会拒绝运行；其它增益、占空比、速度和失速阈值仍需根据实测整定。
6. 使用闭环位流，明确执行短时间速度测试，查看 CSV 中目标速度、实测速度、输出占空比和编码器错误。首次测试不接视觉分拣或机械臂动作。

板端命令格式（已确认设备为 /dev/uio0；部署前仍检查身份）：

```sh
./conveyorctl-aarch64 --uio /dev/uio0 --encoder-monitor
./conveyorctl-aarch64 --uio /dev/uio0 --config conveyor.measured.ini --speed-test-ms 1000
```

`--speed-test-ms` 接受 100..5000 ms，目标速度为配置 max_speed_cm_s。采用现有前馈+PI、积分抗饱和、速度滤波、反向/异常速度/AB 错误/无脉冲检测；测试循环间隔超过 100 ms 会停止，硬件看门狗负责软件阻塞后的兜底。到时、异常或信号退出均尝试禁能并读回状态，不自动清错或重启。此模式使用普通 Linux 调度，不宣称硬实时。

仿真可使用 `--simulate --config conveyor.cm.simulation.ini --speed-test-ms 2000`，其对象是合成模型，不是实际电机参数。
