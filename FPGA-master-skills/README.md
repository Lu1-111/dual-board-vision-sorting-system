# 安路 FPGA / FPSoC 开发技能与 MCP 套件

本项目面向安路 FPGA 与 FPSoC 开发，将设计方法、工具使用和调试经验整理为可供 AI 编程助手调用的技能，并通过 MCP 接口连接 TD、FD 开发工具。内容以 DR1 系列、DR1M90 器件及米联客 F3P-CZ02 开发板为主要参考，覆盖 PL、PS、Linux 与 NPU 协同开发场景。

技能围绕具体开发任务组织，包含开发流程规划、PL 设计、PL 调试、PS 软件开发、SoC 联调、NPU 模型部署、量化排障及工具自动化。各专题提供工作流程、接口约定、问题定位方法与参考依据，帮助开发者在需求、硬件设计、软件实现和验证结果之间建立清晰的对应关系。

PL 部分涵盖 RTL 与 IP 集成、时钟和复位设计、跨时钟域处理、引脚与时序约束、仿真、综合、布局布线以及板级调试。调试内容包括 PLL、ModelSim、ChipWatcher 和时序报告分析，关注逻辑行为、约束配置、仿真模型与实际硬件之间的一致性。

PS 与 SoC 部分涵盖硬件描述与 BSP 的关联、FD 裸机开发、FSBL、Linux 启动链、设备树和驱动开发，以及 AXI、DMA、缓存一致性、中断和寄存器接口的联调。相关方法强调位流、硬件描述、软件平台和启动产物的版本匹配，并按故障发生的阶段定位软硬件交互问题。

NPU 部分围绕 ONNX 模型兼容性评估、校准与量化、ArmNN 集成、输入输出约定和部署验证展开，区分量化精度、算子支持、模型解析与硬件执行等不同问题。对于普通卷积、深度可分离卷积中的 depthwise 算子和分组卷积，分别讨论对应工具链的支持条件；对于不支持或精度不满足要求的路径，介绍 CPU 分区、SoftNPU 协同、等价图改写、模型结构调整与自定义 PL 实现等方案的适用条件。

MCP 部分为 TD 和 FD 提供本地工具接口，支持环境与工程信息查询、已有工程的构建任务管理、日志读取和报告检索，使开发助手能够结合工程状态开展自动化操作。串口与虚拟机辅助技能覆盖开发板控制台访问和配套 Linux 开发环境操作。具体器件、板卡和软件版本的差异在专题资料中分别说明，实际支持范围取决于目标环境及对应验证结果。
