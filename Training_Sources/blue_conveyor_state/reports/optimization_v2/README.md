# 第二版优化与验证

2026-11-02，在 RTX 5060 Laptop GPU 上完成第二版训练。保持 WorkcellTinyCNN 结构、89,827 个参数、27,546,816 MAC/帧及 224×224 输入规格不变，重新导出 FP32 和 INT8。`models/` 已更新为这一版，初版权重只保留在 Git 历史中。

新生成的第三批 18 张测试图中，两种导出均为 18/18 最高类别正确；按原有 0.8 阈值，17 张明确正确，1 张暗光蓝块输出不确定。未利用第三批结果再训练或调整阈值。

## 训练与量化

使用原先 264 张训练图进行梯度更新，67 张内部验证的划分不变。第二批 24 张分类图片仅用于开发验证和选择训练轮次，未进入梯度更新或 INT8 校准；4 张边界图不参与选择。所有数据用途见 [usage.json](../../data/usage.json)。

从初版权重继续训练，增强明暗、冷暖色温、对比度、伽马、平滑阴影和轻微噪声/模糊。增强保留传送带几何布局，图像灰色补边不被增强改变。优化器 AdamW，学习率 0.0005，批量 24，权重衰减 0.005，标签平滑 0.015，余弦学习率，共 100 轮。按内部验证与已知开发集的宏平均 F1、交叉熵选择第 20 轮。

训练循环 32.35 秒，峰值张量显存 119.66 MiB；PyTorch 2.7.1+cu128。训练曲线存在波动，保存的是所述验证规则选中的第 20 轮，未直接采用最后一轮。

INT8 仍仅使用原训练集每类 40 张、共 120 张进行校准。FP32 ONNX 为 362,064 字节，INT8 ONNX 为 109,708 字节；普通 Conv/ReLU/AveragePool/Gemm 算子结构不变。PyTorch 与 FP32 ONNX 最大绝对输出误差为 0.00001550，内部验证的两种导出均为 67/67。本次没有 FPGA 编译或硬件实测。

## 新生成测试的审核

内置 image_gen 以同一张认可的传送带参考图生成第三批 18 张图片，每类 6 张，均逐张目视检查后统一推理。完整设计、提示词、模型冻结哈希与时间见 [第三批方案](../../data/test_batches/batch03/plan.json)，图像来源和审核记录见 [第三批清单](../../data/test_batches/batch03/manifest.json)。未删掉预测较差的样本。

部分生成效果弱于设计：阴影边界较柔和，部分冷色色偏及噪声较轻，右端蓝块实际仍偏右半带面，伸入两根手指的图片还露出了明显手背。这些偏差都在推理前记录。测试结论描述的是这批固定场景生成图片，不把 18/18 解释为所有工况均已解决。
