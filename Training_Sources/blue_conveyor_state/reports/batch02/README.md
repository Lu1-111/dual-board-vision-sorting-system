# 第二批固定传送带生图测试

2026-11-02，使用内置 image_gen，参照项目已认可的传送带图片新生成 28 张图片。保持相机视角与传送带背景一致，仅使用蓝色方块；本次测试没有重新训练、选择模型、量化校准或调整阈值。

24 张三分类图片中，FP32 正确 22 张（91.67%），INT8 正确 23 张（95.83%）。冷暗光下的空带是两种模型共同的错误。使用原有 0.8 阈值后，FP32 有 2 张、INT8 有 3 张输出“不确定”；其余明确输出的三分类结果均正确。

用户确认：蓝块斜卡下边轨仍输出“物块在位”可以接受，此项仅保留为观察记录，不作为验收问题，也未在事后加入三分类准确率分母。

## 结果

| 指标 | FP32 | INT8 |
|---|---:|---:|
| 空带 | 7/8 | 7/8 |
| 物块在位 | 7/8 | 8/8 |
| 人工干预 | 8/8 | 8/8 |
| 最高概率类别准确率 | 22/24，91.67% | 23/24，95.83% |
| 宏平均 F1 | 0.9165 | 0.9582 |
| 按 0.8 阈值输出不确定 | 2/24 | 3/24 |
| 明确输出覆盖率 | 22/24，91.67% | 21/24，87.50% |
| 明确输出中的错误 | 0/22 | 0/21 |

“最高概率类别正确”与“实际输出明确类别”分别统计。例如 INT8 对靠下边轨的蓝块选中了正确类别，但概率只有 50.95%，最终仍输出不确定。不能把 23/24 解读为有 23 张输出了确定结论。FP32 与 INT8 在全部 28 张图片中的最高类别一致率为 27/28；这批结果不足以说明量化后普遍更准确。

## 需要关注的图片

| 图片 | 实际内容 | FP32 最高类别/概率 | INT8 最高类别/概率 | 最终输出 |
|---|---|---|---|---|
| b02_04 | 冷色偏暗光照，空带 | 物块在位 50.94% | 物块在位 68.24% | 两者均不确定 |
| b02_11 | 暖色侧光，蓝块靠下边轨且完整在带内 | 人工干预 44.68% | 物块在位 50.95% | 两者均不确定 |
| b02_22 | 蓝色袖口，裸手抓住蓝块 | 人工干预 82.66% | 人工干预 73.40% | FP32 人工干预，INT8 不确定 |

其余 21 张三分类图片在两种模型中均给出正确的明确类别。手形阴影没有误判为手，旋转、缺角、阴影覆盖及运动模糊的蓝块也均被识别为物块在位。b02_11 同时包含位置和暖光变化，不能仅凭这一张把问题归因于边缘位置。

当前主要需要补充的验证条件是冷暗光空带、暖光下靠下边轨的蓝块，以及蓝色袖口的手。若以后利用本批错误样本改善训练，需要另外留出未用于改进的新测试图片。

## 额外观察的 4 张边界图片

这 4 张在推理之前就被指定为边界观察，不计入三分类准确率，类别字段为 null。保留全部结果，没有根据预测成败筛图。

| 图片 | 内容 | FP32 最高类别/概率 → 最终输出 | INT8 最高类别/概率 → 最终输出 |
|---|---|---|---|
| b02_25 | 蓝块完全在下方纸板上 | 空带 96.75% → 空带 | 空带 96.32% → 空带 |
| b02_26 | 蓝块完全在右下带外 | 空带 96.16% → 空带 | 空带 95.52% → 空带 |
| b02_27 | 蓝块倾斜跨上边轨 | 空带 81.28% → 空带 | 空带 78.79% → 不确定 |
| b02_28 | 蓝块倾斜跨下边轨 | 物块在位 90.62% → 物块在位 | 物块在位 92.86% → 物块在位 |

b02_28 按用户确认属于可接受行为。模型目前识别的是空带、物块在位、人工干预三个状态，没有单独的掉落或卡料输出。

## 测试设计与审核

先保存 28 项方案和三个模型文件的 SHA-256，再以同一张 `S01_blue_normal.png` 为参考逐张生成；完成逐图目视检查和清单登记后才运行模型。28 张均保留，模型文件及阈值没有变动。与训练候选、来源参考和首批测试图片相比，没有文件内容完全相同的图片。

| 分组 | 数量 | 设计覆盖 |
|---|---:|---|
| 空带 | 8 | 斜向阴影、手形阴影、暖亮光、冷暗光、反光、失焦、低光颗粒、条带阴影 |
| 蓝块在位 | 8 | 左端、上边轨附近、下边轨附近、右端暗光、旋转、缺角、阴影、运动模糊 |
| 人工干预 | 8 | 伸入手指、部分手掌、前臂、左手捏块、较深肤色、蓝色袖口、阴影、空带上悬手 |
| 边界观察 | 4 | 两种带外位置、上下边轨倾斜跨放 |

图片均为 RGB，27 张为 1672×941，1 张为 1671×941，统一采用交付模型规定的等比例缩放与补边预处理。图片没有经过后续人工绘制或拼贴。

生成结果与设计存在以下偏差，已在推理前记录：b02_01 阴影较柔和；b02_17 除两根手指外还露出明显手背，不能代表极少指尖可见；b02_18 可见手部范围大于半掌；b02_07 的低光颗粒及 b02_23 的暗化较轻；b02_16 运动拖影比计划明显。完整逐图审核意见保存在清单中。本次结果仅描述这批同背景生成图片。
